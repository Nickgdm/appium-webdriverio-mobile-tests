## Cenário automatizado

Nesta atividade foi escolhido o fluxo de **Drag and Drop**.

### Abra o terminal e use o comando: **npm test -- --spec ./test/specs/drag.spec.js**

O teste realiza as seguintes etapas:

1. Acessa a opção **Drag** no aplicativo;
2. Localiza o elemento de origem;
3. Localiza o elemento de destino;
4. Executa a ação de Drag and Drop;
5. Valida o comportamento esperado.
